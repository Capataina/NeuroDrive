Choose this path if your immediate goal is to edit the repository safely rather than study every concept in depth first. It is the shortest route to understanding what will break if you change one subsystem.

- When you meet unfamiliar terms, use `GLOSSARY.md` and the relevant concept file rather than pushing through confusion.
- If you are changing observations or reward logic, do not skip the analytics/debugging system file.
