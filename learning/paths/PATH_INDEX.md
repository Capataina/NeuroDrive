# Path Index

The path system exists because there is no single correct way to learn this repository.

## Available Paths

- `foundations-path.md`
  For learners who want theory before systems.
- `project-architecture-path.md`
  For learners who want the fastest top-down understanding of the current runtime.
- `implementation-first-path.md`
  For learners who want to make safe code changes soon.
- `reinforcement-learning-path.md`
  For learners focused on the A2C baseline and its limitations.
- `neuroscience-path.md`
  For learners focused on the project’s brain-inspired ambition rather than only present code.
- `debugging-and-observability-path.md`
  For learners who care most about validation, diagnostics, and experiment discipline.

## How To Choose

- If your main question is "What exists right now?", choose `project-architecture-path.md`.
- If your main question is "How does the current learner work?", choose `reinforcement-learning-path.md`.
- If your main question is "What is this project ultimately trying to become?", choose `neuroscience-path.md`.
- If your main question is "How do I avoid breaking the runtime while editing it?", choose `implementation-first-path.md`.
- If your main question is "How do I tell whether training behaviour is real or misleading?", choose `debugging-and-observability-path.md`.
